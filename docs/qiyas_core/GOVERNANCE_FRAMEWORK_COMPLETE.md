### 7.2 SifatVector (6-Axis Requirement)

**Current (insufficient):**

```python
# 3 axes — CANNOT distinguish all letters

```

**Required (6 axes):**

```python
@dataclass(frozen=True)
class SifatVector:
    voicing_axis: VoicingValue      # VOICED vs VOICELESS
    manner_axis: MannerValue        # STOP, FRICATIVE, NASAL, APPROXIMANT, LATERAL
    nasality_axis: NasalityValue    # NASAL vs ORAL (ب vs م distinction)
    frication_axis: FricationValue  # FRICATIVE vs NON_FRICATIVE (و vs ف distinction)
    continuancy_axis: ContinuancyValue  # CONTINUANT vs NON_CONTINUANT
    emphasis_axis: EmphasisValue    # EMPHATIC vs NON_EMPHATIC (س vs ص distinction)

    residuals: tuple[Residual, ...]
    evidence: EvidenceSet
    rank: EvidenceRank
```

**Why 6 axes required:**

```
❌ 3 axes CANNOT distinguish:
  ب (BAA)  vs  م (MEEM) — need NASALITY axis
  و (WAW)  vs  ف (FAA) — need FRICATION axis
  س (SEEN)  vs  ص (SAAD) — need EMPHASIS axis (already have)
  ت (TAA)  vs  د (DAL) — need VOICING axis (already have)

✅ 6 axes CAN distinguish all 28+ Arabic letters through fariq negation
```
